# Scrapers

Este diretório contém os bots que coletam dados de montadoras e catálogos de peças.

Arquivo de exemplo: `sample_scraper.py` escreve um JSON de teste em `../core_engine/input.json`.

Notas:
- Em produção use Playwright com rotação de proxies e delays aleatórios.
- Este exemplo é apenas um stub para demonstração local.
